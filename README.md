# Radioactive Releases: the Three Mile Island song list

A working index of every song catalogued in Tom Quinn and Sean Kilcoyne's tapewrecks post
[Radioactive Releases: The Music of Three Mile Island](https://tapewrecks.blogspot.com/2014/03/radioactive-releases-music-of-three.html),
with media links added for songs the post lists without one.

Live page: https://abowser-droid.github.io/tmi-song-list/

New finds are highlighted and tagged NEW. Songs that were researched without turning up a
recording carry a short sourced note on what the release physically is and where copies surface.
